Model Notes

Pricing Model Reference

This dashboard estimates expected contribution by combining the unit margin with a logistic win-probability model. Model 5 is the recommended default, while Model 4b remains the main report model.

Inputs

Customer segment, model family, order size, and the police cost adjustment flow directly into the optimizer.

Optimizer

Golden-section search scans the feasible price interval from cost to MSRP and returns the rounded unit price with maximum expected contribution.

Output

KPIs, chart curves, optimal markers, and the executive sentence are all recalculated from the same model state.

Executive Brief

Pricing Review Summary

Use the simulation dashboard as the live source of truth during pricing review. The recommended price balances win probability and contribution, while the segment toggle highlights how police and corporate buyers respond differently to price and order size.

Decision Frame

Quote within the $15,000-$25,000 feasible range and use the optimal marker as the initial negotiation anchor.

Watch Item

When win probability is high, avoid unnecessary discounts; when it is low, review whether strategic account value justifies deviation.
